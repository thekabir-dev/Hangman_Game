# 🕹️ Enhanced Hangman Game

A fun and interactive console-based Hangman game in Python!  
Challenge yourself to guess the word before running out of lives. Perfect for Python learners and coding enthusiasts.  

---

## 🌟 Features

- 🎲 **Random Word Selection** – Each game chooses a new word for replayability  
- ✅ **Correct Letter Tracking** – Keeps track of letters you’ve guessed  
- 🚫 **No Repeats** – Prevents guessing the same letter multiple times  
- ❤️ **Lives System** – Lose a life for every incorrect guess  
- 🎮 **Interactive Gameplay** – Smooth console interface for an engaging experience  

---

## 🎯 How It Works

1. The game randomly selects a word from a predefined word list.  
2. You guess one letter at a time.  
3. Correct guesses are revealed in the word.  
4. Wrong guesses reduce your remaining lives.  
5. The game ends when you either:
   - Successfully guess the word (**You Win!**)  
   - Run out of lives (**Game Over**)
